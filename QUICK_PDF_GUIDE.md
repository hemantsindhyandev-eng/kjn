---

### Method 2: One Command (if you have Python)
```bash
python3 generate_pdf.py
```
This creates `temp_pandas_notes.html` which you can:
- Upload to Vertopal (above)
- Convert with `wkhtmltopdf temp_pandas_notes.html Pandas_Series_Notes_Formatted.pdf`

---

### Method 3: Command Line (Linux/Mac with wkhtmltopdf)
```bash
# Install wkhtmltopdf first
sudo apt-get install wkhtmltopdf  # Ubuntu
brew install wkhtmltopdf           # Mac

# Then run:
python3 generate_pdf.py
wkhtmltopdf temp_pandas_notes.html Pandas_Series_Notes_Formatted.pdf
```

---

### Method 4: Node.js (Full Puppeteer - Highest Quality)
```bash
npm install puppeteer marked
node convert_to_pdf.js
```
